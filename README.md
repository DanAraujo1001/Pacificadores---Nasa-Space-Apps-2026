# NASA Space Apps 2026 — Visual Novel

Visual novel no navegador sobre equipamentos históricos da NASA na Lua e em Marte. Stack: React, TypeScript, Vite, HeroUI, Tailwind, Zustand, Framer Motion.

## Scripts

- `npm run dev` — servidor de desenvolvimento
- `npm run build` — build de produção
- `npm run preview` — pré-visualização do build

Consulte `AGENTS.md` para arquitetura e convenções do projeto.
