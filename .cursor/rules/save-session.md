# Salvar Checkpoint de Sessão (`MEMORY.md`)

Inspecione os arquivos criados ou modificados recentemente neste workspace e atualize o arquivo `MEMORY.md` seguindo rigorosamente esta estrutura:

1. **Seção `## Estado Atual` (Sobrescrever):**
   - Atualize a **Fase** atual do projeto.
   - Liste objetivamente o que já foi implementado e está funcionando.
   - Atualize a lista numerada **O que falta (Próximos passos imediatos)** removendo o que já foi feito e detalhando os próximos 2 ou 3 arquivos/componentes a criar.
2. **Seção `## Bugs / Bloqueios Conhecidos` (Sobrescrever):**
   - Registre qualquer erro de tipagem, asset faltando ou ajuste pendente. Se não houver, mantenha "Nenhum no momento".
3. **Seção `## Log de Marcos` (Append-Only — NUNCA apague linhas anteriores):**
   - Adicione apenas **1 linha nova** ao final da lista no formato: `- [AAAA-MM-DD HH:MM] Resumo curto do que foi concluído.`

Ao finalizar, confirme apenas com uma frase curta o que foi registrado no checkpoint.
