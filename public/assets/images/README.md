# Imagens

Coloque aqui as imagens do jogo (fundos, ilustrações, itens, etc.).
Servidas a partir da raiz, ex.: `public/assets/images/moon.png` → `/assets/images/moon.png`.

Sugestão de organização (conforme `AGENTS.md`):

- `backgrounds/` — cenários (Mar da Tranquilidade, Gusev, planície ártica marciana...).
- `items/` — artefatos coletados (placa da base Tranquility, roda da LRV, painel do Spirit, núcleo de gelo do Phoenix).
- (sprites de personagens continuam em `public/assets/sprites/{character_id}/`).

Use `.webp` ou `.png` otimizados quando possível.
